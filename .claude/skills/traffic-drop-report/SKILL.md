# Traffic-drop report (draft, to be proven on the first real exports)

Inputs: one site's Search Console export (pages and queries, two periods). Never request more than the agency offers.

Sections, in order:
1. **What changed**: clicks and impressions before and after, with the date the drop started.
2. **Where it happened**: the pages and queries with the largest loss, each with its data row.
3. **Likely causes**: only causes the data supports (position, click-through, page-level loss). Mark anything else as unknown.
4. **What to fix first**: at most three actions, ranked by clicks at stake.
5. **What we could not tell**: gaps in the export.

Rules: every claim cites the row or table it comes from; no ranking promises; the report waits for the founder's review before it goes anywhere; client data stays in the private sheet, never in the repo.
